# Apollo UniFi OS Server Deployment

Automated deployment of UniFi OS Server on Ubuntu Server 24.04 LTS.

## Purpose
Provide Apollo Computers technicians with a standardized, automated installation process for UniFi OS Server and Datto RMM.

## Deployment Process
1. Install Ubuntu Server 24.04 LTS.
2. Run the Apollo deployment script.
3. Enter the requested client and network information.
4. Allow the script to install the required software.
5. Complete UniFi Site Manager registration.
6. Verify Datto RMM registration.
7. Move the device to the correct client site in Datto RMM.

## Security
Do not store Datto RMM enrollment URLs, passwords, API keys, or client credentials in this public repository.
